# IoT Firewall

**[Try the ESP32 dashboard in your browser](https://scaramouche-wanderer.github.io/Iot-Firewall-main/)** to explore simulated wireless traffic and alerts without hardware.

This repository holds the early source layout and [architecture diagram](docs/architecture.png) for an ESP32 wireless intrusion detection project.

**Start with [Iot-Firewall-main](https://github.com/ScaraMouche-Wanderer/Iot-Firewall-main)** for the PlatformIO firmware, native tests, and dashboard. The [demo guide](https://github.com/ScaraMouche-Wanderer/Iot-Firewall-main/blob/main/docs/PRESENTATION.md) shows how to run the simulation locally.
