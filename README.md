# IoT Firewall

This repository holds the early source layout and [architecture diagram](docs/architecture.png) for an ESP32 wireless intrusion detection project.

**Start with [Iot-Firewall-main](https://github.com/ScaraMouche-Wanderer/Iot-Firewall-main)** for the PlatformIO firmware, native tests, and dashboard. Its [demo guide](https://github.com/ScaraMouche-Wanderer/Iot-Firewall-main/blob/main/docs/PRESENTATION.md) shows how to explore simulated traffic and alerts without an ESP32.
